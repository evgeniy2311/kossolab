Политика конфиденциальности

Приложение «Kossolab publish» используется только владельцем канала Kossolab для публикации собственных роликов на собственный канал YouTube и в собственный аккаунт Instagram.

Приложение получает доступ только к аккаунтам владельца: загрузка видео, установка обложки, комментарии к своим роликам. Данные других людей не собираются, не продаются и не передаются третьим лицам. Ключи доступа хранятся в закрытых файлах на компьютере и сервере владельца. Доступ можно отозвать в любой момент в настройках аккаунта Google (myaccount.google.com/permissions) или Instagram.

Использование данных Google API соответствует Google API Services User Data Policy, включая требования Limited Use. Приложение использует YouTube API Services; см. YouTube Terms of Service (https://www.youtube.com/t/terms) и Google Privacy Policy (https://policies.google.com/privacy).

Privacy Policy (English)

“Kossolab publish” is used only by the owner of the Kossolab channel to publish the owner's own videos to the owner's own YouTube channel and Instagram account. It accesses only the owner's accounts (video upload, thumbnails, comments on own videos). No data about other people is collected, sold or shared. Access tokens are stored in private files on the owner's machines. Access can be revoked at any time via Google account permissions or Instagram settings. Use of Google API data complies with the Google API Services User Data Policy, including Limited Use requirements. This app uses YouTube API Services.

Удаление данных / Data deletion

Приложение не хранит данные пользователей. Чтобы удалить доступ, отзовите разрешение в настройках аккаунта. Contact: through GitHub @evgeniy2311.
